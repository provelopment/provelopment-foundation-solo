# Welcome to your starter site

This is the single starter page of the default one-Entity installation. It is
authored Markdown source held in the repository; nothing in this repository
installs, publishes, serves or renders it.

## What this seed describes

One Entity, one Facet, one Site, one Page and one explicit full-locale
representation. The declaration in `publication.json` is the only authority over
what exists; a directory listing and a file name never publish anything.

## What this seed is not

It is not an installer, an activated publication, a preview or a deployable
site. The declared JSON alternative is intentionally absent, so the accepted
JSON-first rule selects this Markdown body and nothing else.
