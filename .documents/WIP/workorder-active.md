## 3. Single unresolved defect/evidence requirement: mapped-view survives originating handles

**Why this matters.** The accepted Windows native reader already has a test-only `mapped_view_proofs` suite in `source_read_native.rs` around baseline lines 1368–1841. It constructs a `PAGE_READWRITE` file mapping, creates a `FILE_MAP_WRITE` view, then drops both the original **file handle** and **section handle** while the writable mapped view survives. That existing fixture tests the `pages/p.en-001.json` route. It does not by itself demonstrate refusal through the new `R03.C2` `content/assets/…` route. R03.C2 must fail closed when that independent mapped view may still mutate bytes. A test with only a live writer handle is **not** the equivalent adversary.

**Minimal approved implementation:** within this already audited Windows test-only nested module, use the existing `Fixture` exclusive-creation guard, `Section`, `WritableView`, `BODY_LENGTH`, and the preexisting Windows mapping helpers. Extend **only the test-owned fixture as necessary** (for example create `content/assets/brand/logo.png` with exactly `BODY_LENGTH` bytes under its already-exclusive content root, or introduce an additional test-only helper bound to that fixture). Keep the legacy `pages/` fixture, all previous mapped-view tests, their assertions and behavior unchanged. The smallest recommended test uses the following outline; this is a contract, **not** a demand to paste code literally:

1. Add one Windows-only test function with a stable distinctive name, e.g. `r03c2_10c_transferred_writable_view_refuses_asset_port_until_unmapped`, inside the existing Windows-only `mapped_view_proofs`. It must be compiled and executed by the unmodified `rust-verify` `cargo test --workspace --all-targets --locked --no-fail-fast` step on `windows-2025`. Do not use `#[ignore]`, environmental XFAIL or skip-on-error.
2. Create the **fresh test-owned** nested Entity asset leaf beneath `fixture.content()`: `assets/brand/logo.png`, ordinary regular file, `BODY_LENGTH == 4096` initially filled with a known byte (e.g. `b'A'`). The path must use no Owner content and no global folder; use exclusive claims already made by `Fixture::new`. Refuse to delete pre-existing material. This asset must be **distinct from** the existing `pages/p.en-001.json` fixture so the proof genuinely exercises the asset namespace.
3. Open that exact asset leaf as a real writable file, create a `PAGE_READWRITE` section with existing `Section::over`, map the full file through existing `WritableView::over`, then **drop both originating handles**. Assert that the surviving view still sees the original data and can actually overwrite it in place at the same length (e.g. `view.fill(b'C')` then check first and last bytes). Do not treat a file handle that remains open as the critical adversary.
4. The required outcome is `EntityAssetSourceV1::Refused` with `GraphicAssetReadRefusalKind::OtherIo` and `ASSET_SOURCE_IO_ERROR` (matching the frozen native Windows sharing-error mapping), **never `Present` bytes**, `MissingSource`, a public projection or partial success. If actual Windows evidence differs, report the exact category and **STOP**; do not broaden assertions, invent mapping or modify production native behavior.
5. Drop/unmap the surviving view; retry the **same asset port, same typed reference and same root capability**. The read must now succeed as `EntityAssetSourceV1::Present` with the exact `BODY_LENGTH` bytes containing the rewrite (`b'C'` throughout), exact byte length, link count one, meaningful physical identity, and a repeat read with matching identity/bytes. The after-release success prevents a refusal arising merely from a bad fixture/path or wrong namespace. No media validity or publication is implied.
6. The test must be deterministic (no sleeps, race scheduling or thread timing), use the existing Windows-gated mapping wrappers and safety comments, avoid any new unsafe/FFI/Win32 import, and release only its test-owned handles, view and fixture through guards. A panic must not delete a directory not owned by the test.
