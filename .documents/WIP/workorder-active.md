## 3. Required product outcome and typed design — C1

**One four-format application-owned V2 gate:** keep the already accepted `GraphicImageFormatV1` closed to `.png`, `.jpg`/`.jpeg`, `.webp`, and introduce a separate additive `GraphicImageFormatV2` or equivalent typed enumeration with exactly PNG, JPEG, WebP, GIF. Do not add GIF to the still enum or call GIF a still plane. The new versioned application port and request must remain in `solo-application`, not depend on `solo-adapters`, `gif`, OS, filesystem, CLI, executable or provider. Its single adapter receives a parent-owned byte request with original obligation, exact accepted source digest and declared closed format, and returns a typed **still** or **GIF animation** observation or a typed refusal. The application validates all claims itself and never trusts success merely because the adapter returned `Inspected`.

**Four real formats, two distinct result classes:**
- PNG/JPEG/WebP use the **existing** `GraphicImageInspectPortV1`/`ConfinedImageInspectAdapterV1` still-image path with identical decoded RGBA8 digest/size/MIME/dimension and supervisor verification; no forked still decoder.
- GIF uses `inspect_gif_bytes_with_executable_v1` from accepted `crates/solo-adapters/src/graphic_image_inspection.rs` in the WO-112 technical baseline. It receives original GIF source bytes, performs parent source-header/signature/magic checks, runs the real contained worker, validates parent-observed child PID, normal exit, verified limits and reap, exact source digest and validated canonical transcript. It yields a **complete** ordered `GifAnimation` observation: GIF87a/GIF89a signature, `image/gif`, dimensions, intrinsic pixels, frame count, frame rects, authored delays, disposal, palette/transparency/interlace facts, `Absent|Finite(n)|Infinite` loop semantics, cycle duration, aggregate composed-pixel budget, original source digest, bounded transcript digest and each independently tracked composite digest. No GIF first-frame downgrade, implicit static transcode, altered zero delays or synthetic animation.
- No adapter-specific GIF struct is allowed in the inward application crate. Define a closed inward `GifFrameEvidenceV2`/`GifAnimationEvidenceV2` representation and translate at the adapter boundary, or an equally minimal type-safe alternative. Do not duplicate media decoding in application logic. Match all frame/cycle/size arithmetic under checked bounds and reject any impossible cross-field claim, zero/extra frame, mismatched source digest, wrong format or MIME, duplicate/missing index, bad geometry, bad pixel budget or unproved confinement. A well-formed transcript hash checks transport integrity, **not** physical proof that a malicious child reported truthful pixels; do not claim impossible parent-side semantic verification without independently checked pixel bytes.

**One atomic candidate:** `GraphicAssetSourceSetV1`/`GraphicAssetObligationInventoryV1` remains the authoritative input; iterate **every** independently declared Entity image obligation, including `public`, `internal`, unlisted, and later suppressed descendants, in inventory order. Validate each through the real V2 outbound port. Return `Complete` only if every obligation succeeds; any one refusal returns exactly one typed whole-candidate `Refused`, with **no** partial result, emitted publishable artefact, public URL or skipped unsupported asset. Zero-obligation success stays distinct from refused acquisition. The V2 result is a nonpublishing inspected candidate: `grants_publication_authority() == false`, and it does **not** assert a global filesystem snapshot or authorize a route/renderer. Preserve origin/owner/role/reference/provenance and every original identity without squashing sibling declarations or hiding internal/unlisted obligations. An unknown format, AVIF/SVG or platform reference must refuse **for this four-format V2**, not be silently ignored or rebranded as missing; later closure order expands the accepted formats and platform catalogue after actual proof.
